Backend · Java

¿Qué es Spring Boot y por qué utilizarlo?

Una introducción al desarrollo de aplicaciones backend utilizando el ecosistema Spring.

Leer artículo completo ↓

Spring Boot es un framework basado en Spring que simplifica la creación de aplicaciones Java. Permite configurar proyectos con menos código y proporciona herramientas para crear APIs REST.

Entre sus componentes más utilizados están: Spring Web, Spring Data JPA, Spring Security y Spring Boot Actuator.

Una arquitectura común separa la aplicación en Controller, Service y Repository. Esta organización facilita el mantenimiento y la separación de responsabilidades.

Cloud Computing

¿Qué es la computación en la nube?

Comprendiendo cómo ejecutar aplicaciones utilizando infraestructura cloud.

Leer artículo completo ↓

La computación en la nube permite utilizar recursos informáticos a través de Internet, como servidores, almacenamiento, redes y bases de datos.

Existen tres modelos principales: IaaS, PaaS y SaaS.

Por ejemplo, Compute Engine permite utilizar máquinas virtuales, mientras que Cloud Run permite desplegar aplicaciones en contenedores sin administrar directamente los servidores.

DevOps · Docker

Docker y los contenedores

Cómo empaquetar aplicaciones y sus dependencias en entornos reproducibles.

Leer artículo completo ↓

Docker permite empaquetar una aplicación junto con sus dependencias dentro de una imagen.

Un contenedor es una instancia ejecutable de esa imagen.

Docker Compose permite definir y administrar múltiples servicios mediante un archivo compose.yaml. Es especialmente útil cuando una aplicación necesita backend, base de datos y otros servicios.

Database · SQL

PostgreSQL frente a MySQL

Diferencias entre dos sistemas gestores de bases de datos relacionales.

Leer artículo completo ↓

PostgreSQL y MySQL son gestores de bases de datos relacionales muy utilizados.

PostgreSQL destaca por su extensibilidad, cumplimiento de estándares SQL y soporte para tipos de datos avanzados.

MySQL es ampliamente utilizado en aplicaciones web y cuenta con un ecosistema muy extendido.

La elección depende de los requisitos, consultas, modelo de datos y necesidades de la aplicación.

Cloud · Infrastructure

¿Qué es una máquina virtual?

Entendiendo la virtualización y su aplicación en plataformas cloud.

Leer artículo completo ↓

Una máquina virtual es un entorno informático que emula un equipo físico y dispone de recursos virtualizados como CPU, RAM y disco.

En Google Cloud, Compute Engine permite crear máquinas virtuales con diferentes configuraciones de hardware y sistemas operativos.

Son útiles para alojar servicios, administrar servidores y ejecutar aplicaciones.

DevOps · Monitoring

Monitoreo de servidores con Zabbix

Supervisión de recursos, disponibilidad y generación de alertas.

Leer artículo completo ↓

Zabbix es una plataforma de monitoreo que permite supervisar servidores, redes y servicios.

Mediante agentes se pueden recopilar métricas de CPU, memoria, disco y disponibilidad.

Los triggers permiten definir condiciones para detectar problemas y generar alertas. Por ejemplo, advertir cuando el uso de CPU supera un umbral determinado.
